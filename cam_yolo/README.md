# cam_yolo/

YOLO26 image-classification training for tile grades, using the cropped
per-tile photos in `data/roboflow_dataset/` (built by
`development/prepare_roboflow_dataset.py` from the raw `data/` captures —
see that script and `development/README.md`). Classifies a tile photo into
one of the grade folders currently present there: `3A`, `3B`, `4`, `5`.

Not an App Bricks node (like `development/`, this is dev-only tooling, not
one of `acoustic_node/`/`camera_node/`/`pick_place_node/`) and not yet
wired into `camera_node`'s live pipeline — this is model training/
evaluation only. Whether/how the resulting weights get deployed into
`camera_node` is a separate, later decision.

| File | Role |
|---|---|
| `config.yaml` | All tunable parameters — source/output dataset paths, class list, train/val split fraction + seed, training hyperparameters. |
| `prepare_dataset.py` | Splits `data/roboflow_dataset/<grade>/*.jpg` into the `train/<class>/`, `val/<class>/` layout Ultralytics classification training expects ([docs](https://docs.ultralytics.com/datasets/classify/)). Copies files (source images untouched); rerun anytime to regenerate the split. |
| `train.py` | Fine-tunes `yolo26n-cls.pt` (pretrained on ImageNet) on the split dataset. Writes checkpoints/metrics to `runs/tile_grade_cls/`. |
| `val.py` | Validates a trained checkpoint's top1/top5 accuracy against `val/`. |
| `predict.py` | Runs a trained checkpoint against one image or a folder, prints predicted grade + confidence. |
| `dataset/` | Generated by `prepare_dataset.py` — not committed (images are repo-wide gitignored). |
| `runs/` | Ultralytics training output (weights, metrics, plots) — not committed. |

## Usage

```bash
venv\Scripts\activate
pip install -r requirements.txt   # installs ultralytics

# One-time (or whenever you want a different split/seed): build the
# train/val split from data/roboflow_dataset/
python cam_yolo\prepare_dataset.py

# Train
python cam_yolo\train.py

# Evaluate
python cam_yolo\val.py

# Predict on a new photo
python cam_yolo\predict.py path\to\tile.jpg
```

## Known limitations

- Small dataset (~376 images across 4 classes as of 2026-08-20, see
  `data/roboflow_dataset/` counts) — expect this classifier to overfit
  easily; watch the `val/` accuracy in `runs/tile_grade_cls/`, not just
  train loss.
- The `3A`/`3B`/`4`/`5` grade labels come from how the source photos were
  organized during capture, not a validated ground-truth grading pass —
  see `development/prepare_roboflow_dataset.py`'s docstring (repo owner,
  2026-08-16 session): lower grades are known to contain real damaged
  tiles, but no defect-level (crack vs. corner) annotation exists yet.
  This trains a single grade classifier, not a defect detector.
- `imgsz: 224` with default `CenterCrop`/`RandomResizedCrop` transforms
  (Ultralytics classify default) assumes a roughly square input — the
  cropped tile photos from `prepare_roboflow_dataset.py` should already be
  close to square, but this hasn't been specifically verified per class.
