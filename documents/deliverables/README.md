# documents/deliverables/

Documents kl mithunvel's college (VIT Chennai, School of Mechanical Engineering,
BMEE497J/BMHA497J Project 1) requires him to maintain for this project — kept in this
repo for convenience, alongside the engineering work they document. Full source
guidelines: `VIT_Project1_Guidelines.md`.

This is a subfolder of `documents/`, but a distinct kind of content from the rest of it:
`documents/mech`, `electrical`, `programming`, `project`, `requirements` are engineering
documentation; `deliverables/` is coursework/administrative paperwork. A deliverable may
reference or excerpt content from the other `documents/` subfolders, but the reverse
should not happen — engineering docs shouldn't depend on coursework formatting
requirements.
