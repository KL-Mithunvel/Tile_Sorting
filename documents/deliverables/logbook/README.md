Required by the college guidelines (`../VIT_Project1_Guidelines.md` § 5): a daily
logbook of project-related activities, signed regularly by the guide, producible on
request or at any scheduled review.

This is a physical/guide-signed requirement — it can't be fully satisfied by
`.CLAUDE/CLAUDE-LOG.md` alone (that log has no guide signature and isn't daily), but
`.CLAUDE/CLAUDE-LOG.md` is a useful source to draw daily entries from when back-filling
this logbook, since it already records what was done and why per session.

See `Logbook.md` — back-filled dated entries from `.CLAUDE/CLAUDE-LOG.md` covering all
work so far (2026-07-08 through 2026-08-03). This is the drafting/reference copy; the
