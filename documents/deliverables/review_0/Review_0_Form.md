## Project Proposal Writeup

This project proposes an Automated Tiles Sorting and Packing System for Sree Murugan
Tile Works, where clay tile inspection, grading, sorting and packing are presently
labour dependent. Manual handling increases cost, reduces consistency, slows production
flow and makes defect tracking difficult. The proposed prototype will use a conveyor
based tile flow with tile ID tracking at each station. Dimensional processing will
measure tile presence, alignment, length, width and edge deviation to identify size or
shape mismatch. Acoustic processing will record the sound produced by a controlled tap,
remove conveyor/background noise using filtering, apply windowing and FFT, and extract
frequency response features to identify possible internal cracks. Camera processing will
use controlled lighting, image capture, edge detection, surface segmentation and
defect-area estimation to identify visible cracks, corner breakage and surface damage.
The classification stage will combine dimensional, acoustic and visual results to assign
each tile as Grade A, Grade B or Reject. Final deliverable outputs will include a working
conveyor based inspection prototype, integrated sound-image-dimensional processing
workflow, tile grading and rejection logic, pick and place packing mechanism, and
production/defect data logging dashboard. The system aims to reduce manual effort,
improve repeatability, increase throughput, support quality documentation and provide a
scalable automation solution for tile manufacturing industries.
